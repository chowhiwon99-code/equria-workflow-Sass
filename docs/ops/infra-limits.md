## ⚠️ 무료 플랜의 진짜 위험 — 초과하면 과금이 아니라 **중단**

Supabase Free는 한도를 넘으면 요금이 붙는 게 아니라 **서비스가 멈춘다**(Pro는 과금+한도 설정 가능).
게다가 **1주일 미활동 시 프로젝트가 자동 일시정지**된다 — 연휴에 아무도 안 쓰면 서비스가 내려간다는 뜻이다.
프로덕션을 무료 플랜에 두는 것 자체가 이 두 가지 리스크를 안고 가는 것.

| | Free | Pro |
|---|---|---|
| 월 요금 | $0 | **$25** |
| DB | 500 MB | 8 GB (이후 GB당 $0.125) |
| 파일 스토리지 | 1 GB | 100 GB (이후 GB당 $0.0213) |
| Egress | 5 GB | 250 GB (이후 GB당 $0.09) |
| MAU | 50,000 | 100,000 |
| **한도 초과 시** | **서비스 중단** | 과금(Spend Cap 가능) |
| **미활동 시** | **1주일 후 자동 정지** | 없음 |

## 🚨 언제 결제해야 하나 — 아래 중 하나라도 걸리면 보고

1. **파일 스토리지 600 MB 초과** (한도의 60%) ← 지금 149 MB
2. **DB 300 MB 초과** (한도의 60%) ← 지금 19 MB
3. **외부 가입 워크스페이스 10곳 초과** — 1곳당 약 50 MB라 20곳이면 스토리지 한도
4. **SNS 마케팅 개시가 결정된 시점** ← 유입 속도를 예측할 수 없으므로 **개시 전에 미리 전환**
5. 프로젝트가 실제로 일시정지된 적이 있을 때 (그땐 이미 늦음)

> 대표 답변(2026-08-10): "구독할 예정이니 걱정하지 말라" — 즉 **위 조건이 걸리면 시점만 알리면 된다.**

## 📐 워크스페이스 1곳당 실측 원단위 (2026-08-10)

3곳·7명·약 4개월 dogfood 기준이라 표본이 작고, 우리 사용이 일반 회사보다 무거울 수 있다.

| | 1곳당 | 무료 한도로 몇 곳? | Pro 한도로 몇 곳? |
|---|---:|---:|---:|
| DB | 약 6 MB | 약 79곳 | 약 1,300곳 |
| 파일 | 약 50 MB | **약 20곳** | 약 2,000곳 |

**Pro 전환 후 무료 워크스페이스 1곳의 한계비용 ≈ 월 ₩2** (50MB × $0.0213/GB).
→ 무료 사용자를 많이 받는 것 자체는 비용 부담이 아니다. **Pro 기본료 $25가 사실상 전부**이고 유료 고객 1곳이면 덮인다.

## 🔍 측정 SQL — 세션마다 이거 한 번

```sql
select pg_size_pretty(pg_database_size(current_database())) as db,
       (select count(*) from public.workspaces) as workspaces,
       (select count(*) from auth.users) as users,
       (select pg_size_pretty(sum((metadata->>'size')::bigint)) from storage.objects) as storage,
       (select round((100.0*sum((metadata->>'size')::bigint)/(1024^3))::numeric,1)
          from storage.objects) as storage_pct_of_1gb;
```

버킷별로 쪼개 보려면:

```sql
select coalesce(bucket_id,'합계') as bucket, count(*) as files,
       pg_size_pretty(sum((metadata->>'size')::bigint)) as size,
       round((100.0 * sum((metadata->>'size')::bigint) / (1024^3))::numeric, 1) as pct_of_1gb
from storage.objects group by rollup(bucket_id) order by 4 desc;
```

조직 플랜 확인은 Supabase MCP `get_organization`(org id는 메모리 `supabase-project.md`).
